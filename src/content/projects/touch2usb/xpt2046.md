# XPT2046 Controller & Calibration

## Operating Principle
The **XPT2046** is a 4-wire resistive touch controller containing a 12-bit successive-approximation analog-to-digital converter (SAR ADC). When a user presses the screen, the flexible top conductive layer touches the rigid bottom conductive layer, forming a resistive voltage divider across the X and Y planes.

## SPI Protocol & Control Byte
The Pico sends an 8-bit control word over SPI to initiate conversion:
- `0x90`: Measure Y-position (Differential mode, 12-bit resolution)
- `0xD0`: Measure X-position (Differential mode, 12-bit resolution)

The chip responds with two bytes containing the 12-bit ADC result ($0 \dots 4095$).

## Panel Calibration Table
Because resistive glass overlays have manufacturing tolerances, raw ADC boundaries must be mapped to screen display dimensions:

| Dimension | Measured ADC Min | Measured ADC Max | Screen Resolution Range |
| :--- | :--- | :--- | :--- |
| **X-Axis** | `150` | `3784` | `0 – 799` pixels |
| **Y-Axis** | `277` | `3784` | `0 – 479` pixels |

### Linear Interpolation Formula
$$\text{Screen}_X = \frac{(\text{Raw}_X - X_{\text{MIN}}) \times (\text{Width} - 1)}{X_{\text{MAX}} - X_{\text{MIN}}}$$
$$\text{Screen}_Y = \frac{(\text{Raw}_Y - Y_{\text{MIN}}) \times (\text{Height} - 1)}{Y_{\text{MAX}} - Y_{\text{MIN}}}$$

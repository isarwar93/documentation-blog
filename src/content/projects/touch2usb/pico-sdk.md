# Signal Filtering & Noise Suppression

Resistive touch overlays are sensitive to electrical noise generated by backlight inverters, switching DC-DC power supplies, and ambient electromagnetic interference. The `pico_sdk_touch` firmware implements a 4-stage digital signal conditioning pipeline.

```text
[ Raw SPI ADC ] 
       │
       v
[ 1. 5-Sample Median Filter ] ──> Rejects single-sample high/low voltage spikes
       │
       v
[ 2. Linear Screen Remap ]   ──> Scales calibrated ADC limits to 800x480 resolution
       │
       v
[ 3. Exponential Moving Avg ]──> Low-pass filters coordinates (alpha smoothing)
       │
       v
[ 4. Jitter Deadband Filter ]──> Suppresses HID packet dispatch if motion < deadband
       │
       v
[ USB HID Report Dispatch ]
```

## 1. Five-Sample Median Filter
Single ADC noise spikes (frequently observed when fingers shift pressure) are rejected by buffering 5 contiguous samples per axis, sorting them, and selecting the 3rd (median) value.

## 2. Exponential Moving Average (EMA)
To smooth cursor tracking without adding tactile lag:
$$S_t = \alpha \cdot Y_t + (1 - \alpha) \cdot S_{t-1}$$
where $\alpha \approx 0.65$, delivering an optimal balance between low latency and smooth cursor stability.

## 3. Release Guard Debounce
When a finger lifts from the glass, the mechanical separation creates high-frequency micro-bounces on `PENIRQ`. A 300 ms release guard timer ensures drag-and-drop operations do not suffer from accidental touch release interruptions.
